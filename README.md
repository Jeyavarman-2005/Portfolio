An executive, light-themed **Bento Grid Portfolio** designed to showcase the intersection of **Mechanical Engineering** and **Full-Stack AI Software Architecture**. 

Built with React, pure CSS custom design system variables, and modern glassmorphism UI patterns, this application highlights real-world industrial projects, finite element analysis (FEA) work, predictive maintenance AI pipelines, and industrial experience.

---

## 🌟 Key Features

* **Bento Grid Architecture**: Clean, modular grid layout presenting technical competencies, key metrics (9.10 CGPA, 4 Internships, 10K Runner), Ubuntu/Docker dev environment, and core skill sets.
* **Dynamic Glassmorphic Navbar**: Scroll-aware header that transitions from transparent to a blur-behind frosted glass navigation bar.
* **Industrial Experience Timeline**: Interactive chronological vertical layout detailing engineering roles at Rane (Madras) Limited, Prime Tooling's, and Motherson Automotive Elastomers.
* **System Architectures Showcase**: Highlighted project cards for industrial RAG-powered assistants, CAE autonomous drone development, and UAV air-quality monitoring payloads.
* **Responsive Design System**: Custom media queries engineered for high-density desktop screens, tablets, and mobile viewports.

---

## 🛠 Tech Stack & Tools

### Software & Web Development
* **Frontend**: React.js (Hooks: `useState`, `useEffect`)
* **Styling**: Vanilla CSS3 (Custom Properties, CSS Grid, Flexbox)
* **Typography**: Plus Jakarta Sans & JetBrains Mono (via Google Fonts)
* **Backend & AI Ecosystem**: Python, FastAPI, RAG Models, PostgreSQL, Docker

### Engineering & CAE Core
* **CAD/CAM**: SolidWorks, CATIA V5
* **Simulation & FEA**: ANSYS Workbench (Explicit Dynamics, CFD, Aeroelasticity)
* **Quality & Metrology**: GD&T, Process Optimization, Elastomer Curing Analytics
